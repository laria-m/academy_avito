# Итоговый проект по Python в рамках Академии аналитиков Авито

Исследование данных о лауреатах Нобелевской премии с использованием Nobel Prize API.

В проекте рассматриваются три направления анализа:

1. **География награждений:** страны-лидеры по количеству лауреатов, распределение премий по категориям и динамика награждений.
2. **Возраст лауреатов:** распределение возраста при первом награждении, средний возраст по категориям и его изменение по десятилетиям.
3. **Гендерное распределение:** соотношение мужчин и женщин среди лауреатов, доля женщин по категориям и её динамика по десятилетиям.

## Структура проекта

- `Lokteva_Maria_final_project.ipynb` — основной ноутбук с анализом и визуализациями.
- `json_dict_processing.py` — функции обработки вложенных JSON-словарей.
- `laureates_configs.py` — конфигурации обработки данных лауреатов.
- `prizes_configs.py` — конфигурация обработки данных Нобелевских премий.
- `dataset_helpers.py` — группировка данных.
- `atribute_manager.py` — добавление вычисляемых атрибутов.
- `aggregations.py` — функции для расчёта статистик и агрегирования данных.

## Зависимости

- Python - язык программирования, на котором написан проект
- Jupyter Notebook - среда для запуска ноутбука с анализом
- requests - для получения данных из Nobel Prize API
- matplotlib - для построения графиков

## Запуск проекта

Для запуска проекта необходимо скачать все файлы в одну папку, открыть `Lokteva_Maria_final_project.ipynb` в Jupyter Notebook и последовательно выполнить все ячейки.
